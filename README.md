# تشغيل التطبيق محليًا

لتشغيل هذا التطبيق على جهازك، اتبع الخطوات التالية في الطرفية (Terminal / CMD).

## 1. إنشاء بيئة افتراضية

إنشاء البيئة الافتراضية اختياري، لكنه يُنصح به بشدة لعزل حزم المشروع عن حزم النظام.

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

## 2. تثبيت المتطلبات

إذا كان المشروع يحتوي على ملف `requirements.txt`، يمكنك تثبيت جميع المتطلبات دفعة واحدة:

```bash
pip install -r requirements.txt
```

إذا لم يكن ملف `requirements.txt` موجودًا، يمكنك تثبيت FastAPI وUvicorn مباشرة:

```bash
pip install uvicorn fastapi
```

## 3. تشغيل التطبيق

تأكد أولًا من أنك داخل المجلد الرئيسي للمشروع، والذي يحتوي على ملف `main.py`.

ثم شغّل الخادم باستخدام:

```bash
 python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### شرح الأمر

- `main:app` — يشير إلى ملف `main.py` والمتغير `app` الذي يمثل تطبيق FastAPI.
- `--host 0.0.0.0` — يسمح للتطبيق باستقبال الاتصالات من الأجهزة الأخرى على الشبكة، وليس من جهازك فقط.
- `--port 8000` — يحدد المنفذ الذي سيعمل عليه الخادم.
- `--reload` — يعيد تشغيل الخادم تلقائيًا عند تعديل وحفظ ملفات المشروع، وهو مفيد أثناء التطوير.

## 4. فتح التطبيق

بعد تشغيل الخادم بنجاح، افتح المتصفح وانتقل إلى:

```text
http://localhost:8000
```

يمكنك أيضًا الوصول إلى توثيق FastAPI التفاعلي عبر:

```text
http://localhost:8000/docs
```

## ملاحظات

- تأكد من تفعيل البيئة الافتراضية قبل تثبيت الحزم وتشغيل التطبيق.
- إذا ظهر خطأ متعلق بحزمة مفقودة، تأكد من تنفيذ:

```bash
pip install -r requirements.txt
```

- لإيقاف الخادم، اضغط:

```text
Ctrl + C
```
